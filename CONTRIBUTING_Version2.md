# Contributing to WorkTravel Academy Core

Thanks for helping build the WorkTravel Academy learning ecosystem.

## What We Value

We prioritize:
- practical learning
- clear documentation
- measurable outcomes
- respectful peer review
- real project contribution

## Contribution Types

We welcome:
- course module improvements
- structured learning materials
- project brief updates
- contributor workflow enhancements
- documentation and onboarding improvements

## Standards

- keep changes focused and relevant
- write clearly and consistently
- preserve educational clarity
- document what changed and why
- make improvements easy to understand

## Review Expectations

Please:
- open a clear PR description
- explain the learning or operational benefit
- keep scope focused
- include examples or references where helpful

## Sponsorship and Rewards

Verified contribution pathways support the broader program and may be connected to the Academy credits system.

## Questions

Open an issue or discussion for questions or suggestions.
