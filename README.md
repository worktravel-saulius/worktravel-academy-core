# WorkTravel Academy Core

WorkTravel Academy is a project-based learning ecosystem for developers who want to build practical skills, contribute meaningful work and develop public evidence of learning.

## Mission

We make practical learning visible through:

- focused project work;
- documentation, tutorials and learning resources;
- peer review and governance-aware contribution practices; and
- public, reproducible proof of learning.

## Earn-to-Build programme

The **Earn-to-Build** programme connects learning, contribution and review-first recognition. Eligible contribution evidence may be considered through the programme’s controlled review process.

> A merged pull request, course completion, issue comment or sponsorship is **not** an automatic award, credit, Copilot seat, payment, employment offer or place in a cohort. Recognition, eligibility and any future benefit remain subject to published capacity, identity, policy and human-review controls.

## Contribution areas

- AI engineering learning paths
- software engineering project work
- contribution verification and governance
- public documentation and tutorials
- community-driven technical development

## Get involved

1. Read the relevant contribution guidance before opening a focused pull request.
2. Keep changes small, evidence-backed and easy to review.
3. Use [`contributor-verification-system`](https://github.com/worktravel-saulius/contributor-verification-system) for review-first contribution standards and staged integration controls.
4. Explore [`developer-learning-paths`](https://github.com/worktravel-saulius/developer-learning-paths) for practical learning materials and portfolio-oriented outputs.

## Automation boundary

The repository documentation and workflows are intentionally non-operational. They do not award credits, redeem points, create coupons, provision Copilot seats, collect member data, send member messages, or change Wix, Google Cloud or payment systems.
