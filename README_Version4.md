# WorkTravel Academy Core

WorkTravel Academy is a project-based learning ecosystem that helps developers earn tool access, project credibility, and community recognition through verified contribution workflows.

## Mission

We make practical learning measurable:
- real project work
- merged pull requests
- documentation and tutorials
- peer review and governance
- public proof of learning

## Earn-to-Build Model

Developers earn credits for verified contribution and can redeem them for:
- GitHub Copilot seats
- cloud credits
- AI tooling access
- project support resources

## Core Program Pillars

- Project-based learning
- Verified contribution workflows
- Governance-aware PR review
- Public accountability and evidence
- Tooling and education funding

## Featured Program Areas

- AI engineering learning paths
- software engineering projects
- contribution verification and governance
- public documentation and tutorials
- community-driven technical development
